# Reading-notes prompt (for future articles)

Paste the block below into a new chat, then paste the article. Do not put files in the workspace root. One file in `original/`, one in `summary/`, same filename in both.

---

```
I am doing a reading task. Take the article I paste and produce two files. Do not write anything else in the workspace root.

Folders (already exist):
- original/
- summary/

Filenames (same in both folders):
{Article Title} - {Author}.md

Use the article’s real title and author. No colons, quotes, or other illegal filename characters. Do not name files original.md, summary.md, or anything generic. Do not put “summary” in the filename. Example of the pattern already in this folder:
- original/Defining Technology - Adam Thierer.md
- summary/Defining Technology - Adam Thierer.md

FILE 1 — original/{Article Title} - {Author}.md
Put ALL original words. Every word I pasted: title, byline, date, intro, body, notes, footnotes, original-language text, and page chrome if I included it. Do not rewrite, trim, paraphrase, or add your own headings. This is the source copy.

FILE 2 — summary/{Article Title} - {Author}.md
A fast-read version that still covers EVERY important point the author makes. This is not a thin abstract. I need to be able to read it as fast as possible and still have the author’s full argument.

Rules for the summary:
- Lead with what the piece is and the author’s core claim / thesis.
- Then cover every main point, in the author’s order.
- Keep all lists, slogans, definitions, numbered tasks, historical claims, diagnoses of problems, and proposed fixes.
- Keep names of programs, institutions, dates, and key quoted phrases I would be expected to remember.
- If the paste includes an editor’s introduction plus a primary text, cover both: the intro’s framing and the author’s argument.
- Compress hard. Use short bullets and headings. No fluff, no “in conclusion,” no extra interpretation, no outside research.
- Include a short “lines worth remembering” section at the end for slogans, thesis lines, and distinctive terms.

After writing both files, tell me the two paths and nothing else I need to do.
```
